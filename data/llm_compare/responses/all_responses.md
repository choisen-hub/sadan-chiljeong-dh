## 핵심 발견 (Findings)

### 1. 동일 표본 200문장에 대해 LLM 3사가 분기

동일 텍스트를 입력했을 때 GPT는 "공존(C)", Gemini는 "수동·관계 우세(B)", DeepSeek는 "공존이나 비율 불안정"으로 응답이 분기한다. 본 연구의 다의성 가설(동일 텍스트가 해석자에 따라 다르게 읽힌다)을 LLM 차원에서 외부 재현한 결과로 해석할 수 있다.

### 2. 데이터 X → 데이터 O 전환에서 모델별 응답 안정성 차이

- **GPT-5.5 Instant**: prior와 in-context 결론이 합치 (C 유지)
- **Gemini 3.5 Flash**: prior(C)와 데이터(B) 충돌 시 데이터에 의해 입장 변경 — 텍스트의 힘이 가장 강하게 작동
- **DeepSeek V4**: prior(C) 유지하나 비율 추정 변동성이 큼 — 표본 간 일관성이 낮음

### 3. 사전학습 prior의 문화권 분기 부분 검증

데이터 X 셀에서:
- GPT, Gemini는 공통적으로 "理無情意，無計度，無造作"을 핵심 근거로 인용
- DeepSeek는 "理乘氣", "理主乎氣" 계열을 핵심 근거로 인용

각 모델 학습 데이터의 문화권 차이가 사전학습 prior로 사용하는 텍스트 메모리에 반영된 것으로 해석 가능. 단 데이터 O 셀에서는 모든 모델이 표본 문장을 정확히 인용하여 in-context 추론이 prior 영향을 능가함.

### 4. 본 연구 메인 방법이 못 잡은 의미 차이를 LLM 비교가 보완

보고서 6.4 절 "기대 효과 (2)"의 직접 대응 결과. SikuBERT 토큰 임베딩 클러스터링이 포착하지 못한 능동/수동의 의미 분기를, LLM은 응답 입장(A/B/C)과 비율 추정(%)이라는 정량 형태로 제공한다.

- **v2**: 위 줄의 앞부분 "본인의 사전 지식에만 의존하지 말고," 삭제 — 데이터 X 셀에서 사전학습 prior 외 답할 근거 없는 상태와 자기모순적이었음
- v1으로 받은 응답: 셀 7-9 (재실험으로 v2 갱신) / B1 (부록 보존)
- v1 셀 7-9 응답은 부록 B2-B4로 보존하여 v1 vs v2 비교 데이터로 활용

## 응답 코딩 스키마

- **입장**: A(능동 우세) / B(수동·관계 우세) / C(공존)
- **근거 유형**: T(텍스트 인용) / G(일반론·사전학습) / M(혼합) / ∅(없음)
- **한계 자각**: Y(스스로 한계 언급) / N
- **응답 형식 준수**: Y(첫 줄 A/B/C) / N
