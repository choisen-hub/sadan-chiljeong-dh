## 2. 4-분면 매트릭스 (Step 1 × Step 2)

|  | **Step 2 (공기어) 분화** | **Step 2 (공기어) 동질** |
|---|---|---|
| **Step 1 (의미) 분화** | **A. 완전 분화** ⭐ | **B. 의미만 분화** |
| **Step 1 (의미) 동질** | **C. 결합만 분화** | **D. 완전 동질** |

### 시나리오별 해석

- **A (완전 분화)**: RQ1 Yes 강. 거시·미시 triangulation. 본 연구 가설을 가장 강하게 지지.
- **B (의미만 분화)**: 부분 Yes. 직접 어휘 결합은 일관되나 추상적 의미 공간에서 다층성 존재. 깊은 다의성 가능성. *단 noise 가능성 검토 필수.*
- **C (결합만 분화)**: 부분 Yes (가설 약화). 표면 어휘는 다양하나 의미는 수렴. 단일 개념의 다양한 표현으로 해석.
- **D (완전 동질)**: RQ1 No. 본 연구 가설 기각. 사단칠정 논쟁 원인은 텍스트 외부에서 찾아야 함.

## 3. 정량 임계값 (잠정 — 미팅 7에서 김바로 교수님 검토 예정)

⚠️ 모든 임계값은 도메인 직관 기반 **임의 설정**. 한문 NLP 정립된 기준 부재.

### Step 1 (k-means + silhouette)

| 항목 | 분화 판정 |
|---|---|
| Best-k의 silhouette score | ≥ 0.15 |
| k 선택 | silhouette argmax (k=2~10 중) |
| 정성 검증 (메인) | 각 클러스터에서 random 50문장 추출, 의미 구분 가능 여부 검토 |

### Step 2 (PPMI 공기어)

| 항목 | 분화 판정 |
|---|---|
| 공기어 PPMI top-30 set 비교 | 클러스터별 set overlap ≤ 30% (Jaccard ≤ 0.3) |
| 윈도우 robustness | ±2/±5/±10에서 결과 일관성 확인 |

### Step 3 (대조군 차별성)

| 항목 | 차별성 판정 |
|---|---|
| silhouette 비교 | 理의 silhouette > 心/性/天 평균 + 0.05 |
| 공기어 다양성 비교 | 理의 클러스터 간 공기어 set Jaccard < 心/性/天 평균 |

→ 대조군과 차별 없으면 "理 고유 다층성"이 아니라 "한문 추상 개념 일반의 다층성"으로 결론 수정.

---

## 4. 정성 판단이 메인

silhouette·PPMI 같은 정량 지표는 한문 도메인에서 검증된 임계값 부재 → **각 클러스터의 의미 차이를 사람이 읽고 판단**하는 게 메인. 정량은 보조 / 재현성 확보용.

판단 표준:
- 클러스터별 50문장 random sample
- 어드바이저(김바로/양일모) cross-check 가능하면 더 좋음
- "능동/수동 축에 align"되는지는 RQ1과 별개. 그건 RQ2-3 영역.

## 5. 보고 시 명시할 것

논문 작성 시 다음 사항 footnote 또는 method 섹션에 명시:

1. balance_ratio 등 후보 선정 metric은 **ad hoc 설계**
2. silhouette 0.15 등 임계값은 한문 도메인 표준 부재로 **임의 설정**
3. 정성 판단이 메인, 정량은 재현성 확보용
